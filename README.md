# Storage Benchmark Analyzer

This is a Python project for analyzing storage benchmark results generated by fio.

The project analyzes four types of workloads:

- Sequential Read
- Sequential Write
- Random Read
- Random Write

## Features

- Read benchmark data from JSON and LOG files.
- Extract IOPS, bandwidth, and latency.
- Calculate statistical results.
- Generate performance charts.
- Perform basic data analysis.
- Generate HTML reports.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- fio

## Folder Description

- **data/raw:** Stores the original benchmark JSON and LOG files.
- **fio_configs:** Contains the fio configuration files for the four workloads.
- **src:** Contains Python scripts for data parsing, metric calculation, visualization, and analysis.
- **reports:** Stores generated charts and HTML reports.
- **main.py:** Runs the benchmark analysis process.
- **requirements.txt:** Lists the required Python packages.

## Reports

The project generates separate reports for each workload and one combined HTML dashboard.

The reports include:

- Performance metrics: IOPS, bandwidth, and completion latency.
- Statistical analysis: Mean, median, minimum, maximum, standard deviation, and percentiles.
- Performance charts: IOPS, bandwidth, and latency over time.
- Data distribution: Histograms and boxplots.
- Correlation analysis: The relationship between IOPS and bandwidth.

The combined dashboard is saved as:

`reports/benchmark_dashboard.html`

## How to Run

1. Install Python and fio.
2. Install the required Python packages:

```bash
pip install -r requirements.txt
```

3. Run the program:

```bash
python main.py
```

The analysis results and charts will be saved in the `reports` directory.

Test Configuration and Limitations

  • Benchmark data was collected using fio.
  • Sequential workloads use 128 KiB block sizes.
  • Random workloads use 4 KiB block sizes.
  • Time-series logs represent aggregated measurement intervals, not individual I/O operations.
  • The current configuration uses direct=0. Operating system caching may influence results.
  • IOPS and bandwidth are mathematically related through block size.
These results demonstrate a benchmark data analysis workflow. They should not be treated as definitive measurements of physical SSD performance.

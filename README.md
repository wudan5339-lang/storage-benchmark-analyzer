# Storage Benchmark Analyzer

A Python-based tool for analyzing storage benchmark results generated by [fio (Flexible I/O Tester)](https://github.com/axboe/fio).

This project processes fio JSON and log files, performs statistical analysis and exploratory data analysis (EDA), and generates performance visualizations and a combined HTML dashboard.

## 1. Project Overview

Storage performance can be evaluated using several key metrics, including Input/Output Operations Per Second (IOPS), bandwidth, and completion latency.

The goal of this project is to develop a data analysis workflow that processes benchmark results and identifies performance patterns across different storage workloads.

Four workload types are included:

- Sequential Read
- Sequential Write
- Random Read
- Random Write

The project uses Python to automate data parsing, statistical analysis, visualization, and report generation.

## 2. Key Features

### Data Parsing

- Parse fio JSON output to extract benchmark configurations and overall performance metrics.
- Parse fio log files containing time-series performance data.
- Organize benchmark results using Pandas DataFrames.

### Performance Analysis

Calculate descriptive statistics for IOPS, bandwidth, and completion latency:

- Mean and median
- Minimum and maximum
- Standard deviation
- 95th, 99th, and 99.9th percentiles
- Coefficient of variation (CV)

### Exploratory Data Analysis (EDA)

- Histograms to examine data distributions.
- Boxplots to visualize data spread and potential outliers.
- Correlation analysis to examine the relationship between IOPS and bandwidth.

### Data Visualization

Generate time-series charts to illustrate performance changes during benchmark execution:

- IOPS trends
- Bandwidth trends
- Completion latency trends

### HTML Dashboard

Generate a combined HTML dashboard containing:

- Overall performance comparison across four workloads.
- Individual workload configurations and performance metrics.
- Time-series descriptive statistics.
- EDA results and visualizations.
- Experimental limitations and interpretation notes.

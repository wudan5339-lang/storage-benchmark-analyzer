# Storage Benchmark Analyzer

A Python project for analyzing storage benchmark results generated by [fio](https://fio.readthedocs.io/).

The project processes benchmark data from four storage workloads:

- Sequential Read
- Sequential Write
- Random Read
- Random Write

## Features

- Parse benchmark results from fio JSON and LOG files.
- Extract IOPS, bandwidth, and completion latency.
- Calculate descriptive statistics, including mean, median, minimum, maximum, standard deviation, and percentiles.
- Visualize performance metrics over time.
- Analyze data distributions using histograms and boxplots.
- Generate individual workload charts and a combined HTML dashboard.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- fio

## Folder Description

- **data/raw/**: Stores the raw benchmark JSON and LOG files generated by fio.
- **fio_configs/**: Contains the fio configuration files for the four workloads.
- **src/**: Contains Python modules for parsing data, calculating metrics, generating visualizations, and performing exploratory data analysis.
- **reports/**: Stores generated charts and HTML reports.
- **main.py**: Runs the complete benchmark analysis pipeline.
- **requirements.txt**: Lists the required Python packages.

## Reports

The project generates individual charts for each workload and one combined HTML dashboard.

The reports include:

- **Performance metrics:** IOPS, bandwidth, and completion latency.
- **Statistical analysis:** Mean, median, minimum, maximum, standard deviation, and percentiles.
- **Performance trends:** Line charts showing how IOPS, bandwidth, and completion latency change over time.
- **Data distributions:** Histograms and boxplots to examine the distribution and variability of performance metrics.

The combined dashboard is saved as:

`reports/benchmark_dashboard.html`

## How to Run

### 1. Install Python and fio

Make sure Python and fio are installed on your system.

### 2. Install the required Python packages

```bash
pip install -r requirements.txt
```

### 3. Run the analysis

Run the following command from the project root directory:

```bash
python main.py
```

The generated charts and HTML dashboard will be saved in the `reports/` directory.
